# Production Roles & Capability Registry

StudioHub supports the complete organizational role registry required for feature film and episodic visual effects workflows.

---

## 1. Internal Production Roles

- **Executive Producer**: Global show bidding, contract approval, top-level studio budget visibility, cross-project allocation.
- **Producer / VFX Producer**: Schedule management, milestone delivery approval, task bidding, client communication.
- **Production Manager (PM)**: Day-to-day department crew scheduling, vendor milestones, sequence turnover validation.
- **Production Coordinator**: Dailies playlist organization, task notes logging, status turnover coordination.
- **Production Assistant**: Meeting logging, room prep, read-only review tracking.
- **VFX Supervisor**: Ultimate creative authority on shot/asset approvals, final comp signoff, client presentation approvals.
- **CG / Sequence / Shot Supervisor**: Discipline-specific quality approvals, dailies reviews, technical oversight.
- **Pipeline TD / Technical Director**: Pipeline tool configuration, USD schema plugins, render farm management.

---

## 2. Artist Roles

- **Lead Artist**: Departmental triage, internal dailies review, mentoring, assigning sub-tasks within department.
- **Senior Artist / Artist**: Execution of assigned tasks (Modeling, Rigging, Animation, FX, Lighting, Comp), version publishing, submission for review.
- **Junior Artist**: Sub-task completion, supervised version uploads.

---

## 3. External Partner Roles

- **Vendor Admin**: Vendor account administration, vendor crew provisioning, master vendor delivery dispatch.
- **Vendor Manager / Vendor Producer**: Vendor quota tracking, assignment of vendor-scoped tasks, external batch uploads.
- **Vendor Artist**: Execution of assigned vendor shots/tasks, upload of vendor-branded WIP versions.
- **Client Admin**: Management of client studio reviewer accounts and project associations.
- **Client Producer**: Milestone review signoff, executive notes, master deliverable approvals.
- **Client Reviewer**: Frame-accurate review annotation, approve/reject decisions on client-visible versions.
- **Client Viewer**: Read-only streaming of client-approved media without approval mutation privileges.

---

## 4. System & Oversight Roles

- **Platform Admin**: Cross-tenant configuration and global operations.
- **Auditor**: Read-only compliance validation, access lineage analysis, security audit logs.
- **Viewer**: Read-only observer on project data.
