Before implementing:

1. Read project architecture.
2. Read existing coding rules.
3. Inspect package.json / pyproject.toml.
4. Check current installed versions.
5. Use Context7 for current framework documentation.
6. Do not upgrade dependencies unless requested.
7. Preserve existing architecture.
8. Prefer existing components/utilities.
9. Run type checking.
10. Run tests.
11. Run lint.
12. Run Playwright for UI changes.
13. Never invent API contracts.
14. Verify frontend API against Django API.
