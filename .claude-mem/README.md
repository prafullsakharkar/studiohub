# Local Project Memory

This project uses ClaudeMem as persistent development memory.

Before starting a significant task:

1. Search existing memory.
2. Check previous implementation decisions.
3. Check previous bugs and fixes.
4. Check existing architecture decisions.
5. Reuse previous solutions when applicable.

After significant work:

1. Record architecture changes.
2. Record important implementation decisions.
3. Record bugs and root causes.
4. Record successful fixes.
5. Record performance optimizations.
6. Record testing discoveries.

Never store:
- passwords
- API keys
- access tokens
- private credentials
- secrets
